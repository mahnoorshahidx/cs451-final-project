## Purpose (Problem or Opportunity)

Design and develop a working prototype of a trip budget planner for Commerce Bank. The tool focuses on helping users plan for the financial side of a trip by organizing travel expenses, creating a budget, and determining how much they need to save.

## Goals

Develop a full stack trip budget planner for our capstone project that combines financial planning and trip planning in one application.

## Objectives

- Allow users to create trips.
- Set budgets.
- Estimate expenses.
- Create savings goals.
- Track savings progress.
- Receive personalized trip suggestions.

## Features

### Core Features

- User accounts
- Trip creation
- Expense categories
- Trip budget
- Savings timeline
- Savings tracking

### Advanced Features

- Bank connection
- Shared trips

### AI Implementation

- AI preference quiz
- AI recommendations
- Editable AI-generated itineraries

## Project Scope

Design and develop a working prototype of a trip budget planner for Commerce Bank. The system will focus on trip creation, budgeting, savings planning, expense tracking, and personalized trip recommendations.

## Project Priorities

Complete the core trip planning and budgeting features first, followed by bank integration, AI features, and collaborative trip features.

## Success Criteria

A working capstone prototype where users can:

- Create an account
- Plan a trip
- Create a budget
- Calculate a savings plan
- Track their progress with savings and actual trip expenses
- Successfully use the application's main features

- Limited development time
- AI inaccuracies
- Technical problems

- Features taking longer than expected
