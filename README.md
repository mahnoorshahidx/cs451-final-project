# Trip Budget Planner

## Project Overview
A trip budgeting application that helps users plan travel expenses, track savings goals, manage trip budgets, and monitor actual expenses.

## Project Structure
- `frontend/` — User interface and client-side functionality.
- `backend/` — Java backend and API endpoints.
- `database/` — MySQL schema, database scripts, and sample data.
- `docs/` — Project charter, use cases, requirements, and sprint documentation.

## Technology Stack
- Frontend: React and Node.js tooling
- Backend: Java and Spring Boot
- Database: MySQL

## Development Guidelines
- Work within your assigned project folder.
- Commit and push changes to the shared GitHub repository EVERY time any changes are made.
- Make your commit message DIFFERENT for each file.
- Do not commit passwords, API keys, or other secrets.
- Coordinate API endpoints and database requirements across teams.
- Test changes before merging them into the main branch.
